## P0.4 文件读取与手机快照

```text
任务编号与日期：P0.4 / 2026-10-27
环境：Chrome 155.0.8059.86（无头）；快照视口 390×844（isMobile/hasTouch/DPR3）；真机不可用
步骤或命令：
  npm run build
  npm run verify:import    # scripts/verify-p0-import.mjs，全部走工作台真实 UI
预期结果：多层目录被正确解析为目标映射；损坏结构与非法链接不导致整批失败；

  41/41 项通过。12 个链接 → 预览 13 行；待看 9 条 / 收藏库 9 条；落库 9 条
  （2 条非法协议、1 条同 URL 重复被拦下）；同名不同 URL 均保留；
  标题中的 <script> 以字面量保存且文件内脚本未执行；
  「开发」两个目录映射到预建分类后 3 条入该分类，导入不自动新建分类；
  损坏文件仍进入预览并给出结构性警告；
  手机快照 5563 字节，排除本地专用条目，390×844 无横向溢出，
  禁用脚本仍是 9 条静态列表，快照内搜索「分页」得 1 条、分类筛选得 3 条。
  docs/verification/p0-import-verification.md（原始 JSON 由脚本写入 .verify/reports/，不入库）
状态：解析、写入、快照渲染与只读性通过；手机真机打开未验证
调整或阻塞解除条件：
  真机（iOS Safari / Android Chrome）可用后补测快照打开与长列表滚动；
  收集 User 真实导出的 Chrome / Edge / Firefox 书签文件后复测格式兼容性。
  本轮修正均在验证脚本与断言侧（默认目标为待看、privacy.localOnly 字段位置、
  后台标签页 rAF 轮询失效、hidden 项被计入筛选统计），产品代码未因这四项改动。
```
