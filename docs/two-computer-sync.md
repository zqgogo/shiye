# 家里与工作电脑：收藏双机同步

版本：v0.2 预览 5，2026-11-05。沿用用户自己的 Cloudflare Workers + D1，不需要第二套后端。两台电脑连接同一个地址，使用应用发布凭据（publisher.txt），不需要登录 Cloudflare 控制台。AI 仍在各设备直连模型服务。

## 使用

1. 两台电脑均升级扩展。在「云端与收件箱」填写相同的后端地址和发布凭据，测试连接。
2. 家里电脑点击「检查两台电脑同步」，核对发送、接收、删除和差异，再「确认同步收藏」。首次把本机普通收藏加入共享库，不自动把旧手机镜像当作完整备份导入。
3. 工作电脑同样操作。已有收藏按规范化网址合并，同名同路径分类、同名标签归并；遇到不同内容会要求保留本机或云端，不静默覆盖备注。
4. 平时到一台电脑先同步，使用后再同步。新增、修改、移动、删除都按共同基线交换，不按整库缺失删除别人的新收藏。可以离线编辑，回来再同步。
5. 手机刷新读取共享收藏的白名单视图，不必再发布整库镜像。手机新增仍用 submitter.txt；任意电脑接收手机收藏后同步即可。待看尚未双向同步，继续从高级「待看与旧版镜像」单独发布。

本轮为手动检查、手动确认；不定时上传、不后台自动重试。可勾选「在此设备记住发布凭据」，刷新后进入云端页面自动验证，不自动同步。未勾选时凭据仅当前页面，刷新后重新输入。同步基线保存在当前扩展本机，刷新不会丢失。

## 同步范围

| 数据 | 行为 |
| --- | --- |
| 收藏 | 网址、标题、来源说明、备注、摘录、AI 用途、分类、标签、置顶、未读、禁止 AI、人工字段锁、排序 |
| 分类与标签 | 分类名称、说明、父目录、排序；标签名称。空目录和未使用标签也可同步 |
| 本地专用 | 不发送；仅本地专用记录独占且从未共享的目录/标签不首次上传 |
| 已共享转本地专用 | 本机保留，确认同步后共享库撤回；另一台原副本进入回收站。取消本地专用后可明确重新共享 |
| 删除 | 云端保留删除标记，另一台进回收站，不物理清除其本机记录 |
| 不同步 | 待看、导入与清理历史、来源历史、AI Key/会话/任务、本机设置、最近打开时间、回收站历史和清理快照 |

共享备注等正文会以可读数据存放在自己的 D1；不是端到端加密。手机/只读凭据始终不能读取备注、摘录或完整同步接口，只能读取标题、网址、必要分类标签与标志。

## 差异判定

本机为每个连接保存最后确认的共同基线及实体映射。对比基线、本机与云端三份内容：

- 只有一边修改，传播该边修改；两边内容相同直接确认。
- 两边同时改同条、首次合并同网址内容不同、删除与编辑相撞，逐条展示双方，选择后才能确认。采用整条记录选择，不自动拼接两份备注。
- 首次空库连接不产生“删除全部远端”。此前回收站里同网址与云端活跃内容冲突时也须明确选择。
- 新电脑存在同网址本地专用副本时隔离该项，不下载覆盖私人内容，不误删另一台已有共享；解除本地专用后才能参与合并。
- 分类循环、同级重名或引用冲突由服务端拒绝，不写坏目录。复杂的同时目录重排若无法分批保持合法，会暂停，需先在原电脑调整目录后重新检查。

## 可靠性与协议

- `/v2/info` 提供独立同步版本；`GET /v2/changes` 按上次版本增量读取，固定版本分页，分页期间版本变化即停止重查。`POST /v2/changes` 按记录提交变化，每批最多 50 项/180 KB。
- 稳定键：收藏按规范化网址摘要，标签按 NFC 名称摘要，分类保留身份并在首次连接按路径映射到本机编号。不同电脑不要求相同本地 UUID。
- D1 新增 `0003_two_way.sql`：独立同步状态、实体/删除标记与操作回执。每批按全局基线版本和实体版本比较，原子事务提交；服务端事务随机标记避免失败请求借用别人的成功条件。多台并发时只允许一批先成功，过期预览拒绝覆盖。
- 发送前复核相关记录和隐私，最终写本机前在事务内复核主库身份、同步基线及完整本机指纹。期间编辑不被迟到结果覆盖。
- 上传成功丢响应后，重新检查会识别云端已有结果；不重复创建。部分批次成功时云端保留这些变化，本机保留未完成内容，重新检查继续合并，不承诺整次跨网络同步原子提交。
- 同步回执与本机入库同事务；更新实体会递增本地版本并使旧编辑/AI 基线失效。替换备份或空库迁移切换身份会清本机同步基线，不改云库；下次重新合并。
- 共享库正文总量上限 24 MB，活跃条目上限 50000，含永久删除标记最多 100000。分页按条数和响应字节收紧；服务器回执与删除标记不自动过期。额度是协议边界，真实 Cloudflare CPU、网络和方案容量仍需按实际数据验收。

## 与旧版兼容

新迁移不清旧镜像或收件箱，也不自动同步真实收藏。共享库首次确认后才启用手机新视图；启用后旧 `/v1/mirror` 只返回待看，避免旧客户端继续读取过时收藏。高级镜像发布/清空不改共享库；两台电脑不得把旧版镜像当作双向同步方式。旧镜像存储可另行清空，Cloudflare 管理的备份不承诺物理擦除。

当前两台受信任的个人电脑共用发布凭据，设备 ID 用于操作归属，不提供逐设备独立授权/撤销。需撤销电脑时轮换发布凭据并在保留设备重新填写。手机提交凭据权限保持独立。
