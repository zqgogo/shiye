# 人工测试手册（v1a）

按这份顺序走一遍，约 30–40 分钟，共 **20 项**。

> 262 项自动化断言（9 个回归脚本 + 68 项单测）已经覆盖功能主路径，所以这里**只列自动化碰不到的部分**：浏览器原生右键菜单、真实划词、真机快照，以及几条需要眼睛判断的路径。想复跑自动化看 [`install.md`](install.md) 第 7 节。

## 0. 准备（5 分钟）

### 0.1 构建并加载

```bash
cd /Volumes/sansun/myWork/collectClear/Shiye
git checkout develop && git pull
npm install          # 依赖没动过可跳过
npm run build
```

然后 Chrome 打开 `chrome://extensions` → 右上角开「开发者模式」→「加载已解压的扩展程序」→ 选**绝对路径**：

```
/Volumes/sansun/myWork/collectClear/Shiye/apps/extension/dist
```

三条注意：

1. **已经加载过拾页的，别移除再加载**，在同一条目上点「刷新」即可——移除扩展会连同 IndexedDB 一起删掉。
2. 换加载目录或移除重装，扩展 ID 会变，旧数据不会跟过来。
3. 如果里面已经有真实数据，先到「设置与管理 → 数据」导出完整 JSON 兜底。

### 0.2 建议用独立的浏览器配置文件

Chrome 右上角人像 → 添加 → 在新配置里加载扩展。测试里会造数、删除、替换主库，用独立配置不污染日常收藏。（不强制，但 B 组建议这么做。）

### 0.3 测试材料

| 用途 | 用哪个文件 |
| --- | --- |
| 含重复 URL 与内部链接的书签 | `fixtures/bookmarks-edge.html` |
| 40 层嵌套目录（验证层级上限） | `fixtures/bookmarks-deep.html` |
| 带脚本、超长标题、异常字符的书签 | `fixtures/bookmarks-hostile.html` |
| v1 旧结构备份（验证迁移） | `fixtures/legacy-backup-v1.json` |
| 手机真机 | 任意手机 + 手机浏览器 |

## A. 只能人工做的（6 项）

### A1 右键 · 保存当前页面 · 必测

- [ ] 打开任意正常网页（如 `https://developer.mozilla.org/zh-CN/`），在页面空白处右键 —— 菜单里应看到 **「加入拾页待看」** 与 **「保存到拾页收藏」** 两项
- [ ] 点「保存到拾页收藏」—— 工具栏图标上出现绿色 **✓**，约 4 秒后消失
- [ ] 工作台 →「收件箱」—— 多出这一条，标题是网页标题，链接能点开

> 菜单里没有这两项：先在 `chrome://extensions` 点一次「刷新」，再刷新网页；仍然没有就重启 Chrome（菜单只在扩展安装/启动时创建）。

### A2 右键 · 保存链接 · 必测

- [ ] 在网页里右键**某个超链接** →「保存到拾页收藏」
- [ ] 收件箱里新增的是**那个链接的地址**，不是当前页面地址

### A3 右键 · 保存选中文字 · 必测

- [ ] 在网页里选中一段文字 → 右键 →「保存到拾页收藏」
- [ ] 工作台打开这条详情 —— 「选中文字」里是刚才那段文字

> **这里有个实现选择要你判断**：目前只要有选中文字，标题也会被取成选中文字（截前 300 字），而不是网页标题。也就是说收藏进来标题可能是一句半截的话。我认为该改成「标题用网页标题、选中文字只进选中文字」，你测完说一声，改起来是两行。

### A4 弹窗 · 读取页面所选文字 · 必测

- [ ] 在正常网页选中一段文字 → 点工具栏图标 → 弹窗里点 **「读取页面所选文字」** —— 文本框自动填入，并有提示
- [ ] 点「保存收藏」—— 收件箱出现，详情里「选中文字」有内容
- [ ] 换一个受限页面试（`chrome://settings`、Chrome 应用商店、PDF 预览页）→ 点读取 —— 应给出**可读的错误说明**，不是静默无反应、也不是空白

### A5 弹窗 · 重复收藏与待看 · 必测

- [ ] 对同一个页面连点两次「保存收藏」—— 第二次应提示已在收藏里，不产生第二条
- [ ] 对同一页面点「仅加入待看」再点「保存收藏」—— 待看与收藏各自独立，都能成功

### A6 手机真机快照（P6.4）· 必测

- [ ] 工作台 →「设置与管理 → 数据」→「导出可搜索 HTML ↓」—— 浏览器下载一份 `shiye-collection-<日期>-<时分秒>.html`，同一个新标签页打开预览
- [ ] 把这个文件传到手机（微信文件传输助手 / AirDrop / 邮件均可），用手机浏览器打开
- [ ] 试 **只选分类**、**只输关键词**、**分类 + 关键词同时** 三种组合 —— 结果条数与内容正确，页面能滚动、不卡
- [ ] 记录：机型、系统版本、浏览器与版本

> 这是唯一必须真机的项：触屏、虚拟键盘、iOS 的滚动与字体缩放，桌面 Chrome 的移动视口模拟不出来。

## B. 高风险路径（9 项）

这几条自动化虽有覆盖，但用的是脚本造的数据与脚本点击；真实文件选择器、真实下载弹窗值得亲手过一遍。

### B1 深层目录导入

- [ ] 工作台 → 右上「粘贴 / 导入」→「导入收藏夹」→ 选 `fixtures/bookmarks-deep.html`
- [ ] 预览页顶部出现告警：**「目录层级超过 32 层，更深的目录会合并到上限层级。」**
- [ ] 结果：**1 条新增**，它的目录路径收敛到 32 层（不是 40 层）

### B2 同一个文件导第二遍

- [ ] 接着把 `fixtures/bookmarks-edge.html` 导入一次（记住新增条数）
- [ ] 再导同一份文件
- [ ] 第二次预览里每一行都标 **「已经收藏为「…」」** 且默认不勾选，结果 **0 条新增**

> 注意：现在没有「这个文件你导入过」的文件级提示，只有逐行的 URL 去重。你觉得需要文件级提示就说，我补一句。

### B3 重复行与无效链接

- [ ] 预览 `fixtures/bookmarks-edge.html`
- [ ] 文件内重复的两条：后一条标「本次输入重复，保留第 N 行的第一条」
- [ ] `edge://settings` 那条标「不是有效的 HTTP / HTTPS 链接」，灰色不可选
- [ ] 表格统计（新 / 重复 / 无效 / 疑似）与下方行数一致

### B3.5 损坏条目的备份 · 新增

- [ ] 把任意一份导出的 JSON 里 `bookmarks` 改成 `[{"title":"没有编号也没有网址"}]`，用**替换**方式恢复
- [ ] 应被拒绝并说明「备份里有条目无法恢复（收藏第 1 条缺少编号（id））……替换会清空当前主库，已停止，数据未改动」，刷新后主库原样
- [ ] 同一份文件改用**合并** —— 应成功，结果里写明跳过 1 条、以及「备份里有条目无法恢复」

> 这条是「显示恢复成功、库里却少了一半」的防线，值得亲手看一眼提示是否说得清楚。

### B4 恶意与畸形文件

- [ ] 导入 `fixtures/bookmarks-hostile.html` —— 页面**不弹窗、不跳转、不执行脚本**，标题按纯文本显示
- [ ] 导入一个随便改坏的 HTML（比如把 `fixtures/bookmarks-chrome.html` 里的 `</DL>` 全删掉）—— 给「有链接标签未正常闭合」之类的提醒，不白屏

### B5 v1 旧备份迁移

- [ ] 数据页 → 选择 `fixtures/legacy-backup-v1.json` → 预览能看到条数与导出时间
- [ ] 选「合并」→ 恢复 —— 成功后条目在，界面里没有「价值等级」这类旧字段残留

### B6 替换恢复与安全备份 · 重要

- [ ] 先随便存两三条收藏（方便对照）
- [ ] 数据页 → 选刚才导出的完整 JSON → 模式选 **「替换整个主库（先自动备份）」** → 勾「我了解影响并确认替换」→ 点「替换并恢复」
- [ ] **没勾确认时**应拒绝，并在按钮附近就地显示原因
- [ ] 勾了之后：下载目录里多出一份 `shiye-backup-<日期>-<时分秒>.json`（替换前自动存的），面板显示它的导出时间与收藏/待看/分类/标签条数
- [ ] 恢复完成后提示「主库身份已切换」，并说明旧环境的 AI 交接映射已失效
- [ ] **刷新一下数据页** —— 顶部应出现「有一份替换前的安全备份还没确认保存」，点「保存这份安全备份 ↓」能再下一份，点「已确认保存，清理本机副本」后提示消失（这是「下载失败也不丢」的兜底）

### B7 快照导出：真实下载

- [ ] 同一天连续点两次「导出可搜索 HTML ↓」—— 得到**两个文件名不同**的文件（精确到秒），后一份没有覆盖前一份
- [ ] 打开导出的 HTML：分类下拉、关键词框都能用；断网后打开仍然完整（不依赖任何外部资源）

### B8 AI 交接里的资料选择

- [ ] 「AI 助手 → 制作资料包」→ 勾几条资料 → 点 **「清空已选」** —— 计数归 0，「生成」按钮不可用
- [ ] 再点「全选匹配集」—— 只把**当前筛选下能看见**的条目选上，计数与列表一致
