# 其他设备提交与总机接收（v0.2 预览 4）

2026-11-04，按用户确认实施。正式收藏由总机维护；手机、其他电脑通过自有 Cloudflare 网页提交新增内容。不是全量双向同步，不远程改写或删除总机已有收藏。AI 仍直连用户的模型服务。

## 日常路径

1. 总机先发布镜像，提供共享分类、层级和标签。其他设备用 `submitter.txt` 登录同一个网址；`reader.txt` 仍只能查看。
2. 「添加记录」选择收藏或待看。收藏可选已发布分类、标签，并填写标题、网址、来源说明、备注、置顶、未读和禁止 AI 标志；待看填写标题、网址及备注。不在手机新建分类，避免几台设备创造同名目录。
3. 先保存在「本机临时」；点击发送才上传。提交前提示备注等字段会到自己的 Cloudflare，不应在此发送本地专用内容。
4. 总机「云端与收件箱」检查、预览，勾选接收或退回，每页最多 50 条。接收先本机入库并保存回执，再确认云端。
5. 总机整理后重新准备预览并发布。手机点击「刷新提交与发布状态」，用回执里的正式记录编号核对是否进入当前镜像；不靠标题或网址猜测已发布。
6. 已发布临时项默认从待处理筛选隐藏，仍可查看「全部」或「已出现在发布库」。可逐条或批量清理已发布的本机副本，绝不连删正式收藏或云端提交。

## 状态与保留

| 状态 | 本机临时列表 | 云端收件箱 | 总机正式库 |
| --- | --- | --- | --- |
| 仅本机 | 保留完整内容 | 无 | 无 |
| 已发送待接收 | 保留完整副本 | 保留正文与提交摘要 | 尚未新增 |
| 总机已接收待发布 | 保留副本与回执 | 清除正文，保留摘要和回执 | 已事务入库 |
| 已出现在发布库 | 保留，可手动清理 | 回执 | 已进入当前镜像 |
| 退回 | 保留，显示原因 | 清除正文，保留回执 | 不新增 |

- 每台设备按站点和 serverId/libraryId/epoch 隔离临时列表，另一浏览器/另一设备不会看到这份临时列表。身份切换不会把旧队列发给新库。
- 临时记录仅此浏览器保存，不属于总机备份；退出隐藏私有内容但不删除临时记录，清理站点数据则会丢失。最多 5000 条，受浏览器本地存储实际额度约束；写入失败保留表单，不提示成功。
- 每次只渲染 50 条，提交状态也按 50 个编号查询。云端总收件最多 10000 条（含回执），正式接收页按序号游标分页且按响应字节进一步收紧。
- 待接收内容不自动过期，避免总机久未开机丢记录。已处理回执保留至少 90 天，在后续新提交时清理到期回执；本机副本不自动删除。
- 从当前发布库移除一条已接收记录后，该设备仍有副本时会显示已接收/等待发布，不自动重建总机记录。接收回执在总机元数据中按主库、远端身份和提交编号留存，重试不复活已删除收藏。

## 冲突与中断

| 情况 | 处理 |
| --- | --- |
| 发送成功但响应丢失 | 同一提交编号、同一正文重试；服务端幂等，编号不可换正文 |
| 总机保存成功但确认响应丢失 | 本机回执与记录同事务保存，重试复用原回执，不重复创建 |
| 总机已有同网址收藏 | 保留总机分类、标签、备注与隐私，回执关联已有记录，不覆盖 |
| 同网址收藏在回收站 | 暂不接收，提示先明确恢复或退回，不能静默复活 |
| 分类改名/移动 | 按原分类 ID 接收，使用总机当前分类 |
| 分类或标签删除 | 分类回退未分类，标签跳过，回执说明；原路径仍显示在提交预览和来源里 |
| 同网址已在待看 | 关联现有待看，不覆盖笔记；已完成待看可重新激活，保留原笔记 |
| 本机主库身份变化 | 事务内拒绝接收；重新检查，不把迟到结果写进新主库 |
| 总机重新发布/清空镜像 | 不清待接收收件；清空正式镜像不会删除临时列表 |
| 手动删除本机临时副本 | 仅删除此浏览器副本；已发送提交仍可由总机处理，界面明确确认 |

## 权限与协议

- 旧发布/只读凭据不变，新增独立 `SUBMIT_TOKEN_SHA256`，应用原始凭据仅在本机私有文件。部署工具原地升级，不换项目/账号/库。
- 发布凭据只给总机，读写权限不交给其他设备。提交凭据能查看正式镜像、提交新增、核对本设备状态，不能读取总收件正文、接收、发布或清库。
- 设备随机 ID + 随机设备密钥保存在浏览器，云端仅保存密钥摘要。核对状态须同时有提交登录与本设备密钥，不支持跨设备枚举收件内容。
- 网页登录使用 HttpOnly/Secure/SameSite=Strict Cookie。Cookie 提交必须同源 Origin；扩展发布仍必须 Bearer，Cookie 不能调用发布/清库。
- 接口：`GET /v1/capabilities`；`POST /v1/inbox`（幂等提交）；`POST /v1/inbox/device`（本设备状态）；`GET /v1/inbox?after=序号`（总机分页）；`POST /v1/inbox/:id/receipt`（总机确认）。严格字段白名单，拒绝带凭据网址/非 HTTP(S)，限制正文与响应体积。
- D1 新增 `0002_inbox.sql`，与镜像分片分表，不改动旧镜像数据。接收确认后删除提交正文，但不承诺物理擦除 Cloudflare 管理的备份。

## 侧栏收拢

顶部常驻首页、待看、收件箱、全部收藏；未分类、导入与待整理、回收站收进「更多入口」，进入对应页面自动展开。分类树与工具保持原功能，Cloudflare 入口改为「云端与收件箱」。
