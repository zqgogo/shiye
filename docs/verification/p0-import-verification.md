## 本轮验证暴露的问题（均在脚本/断言侧，产品代码未改）

1. **导入目标默认是「待看」**：第一版脚本按「收藏库」断言，导致行数统计与落库断言失败。实际行为符合设计（"只是想找时间看一眼？先放到待看"），脚本已改为显式切换目标并分别断言两个目标。
2. **`localOnly` 字段位置**：读库断言把 `localOnly` 当成顶层字段，实际存放在 `privacy.localOnly` 下。已修正读取方式。
3. **等待策略在后台标签页失效**：`page.waitForFunction` 默认按 `requestAnimationFrame` 轮询，后台页面 rAF 被节流后，几秒后自动消失的提示条永远等不到（表现为"什么都没发生"）。已改为 Node 侧 `page.evaluate` 轮询（`waitForText` / `waitForSelectorReady` / `waitForSelectorGone`）。
4. **筛选统计方式错误**：快照筛选用 `el.hidden` 实现，`querySelectorAll` 仍会算上隐藏项，导致"筛选没生效"的误判。改为统计非隐藏项后，搜索与分类筛选分别得到 1 条与 3 条。
