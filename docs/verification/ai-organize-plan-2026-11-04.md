# v0.2 预览 2：通用 AI 全范围分片整理

日期：2026-11-04。承接上一轮可用的快速访问、AI 单批操作与 S1 镜像。用户再次明确：**API Key 只用于扩展直连模型服务，Cloudflare 只处理用户主动发布的记录镜像。** 本轮未新增 AI 后端、代理路由或云端凭据保存。

## 怎么用

1. 在「AI 通道设置」配置自己的 DeepSeek / Chat Completions 服务、模型与 Key，分别通过文本及 JSON 测试，然后主动开启。Key 仍只保留在当前工作台内存；刷新或关闭后需重填。
2. 从「AI 助手 → 整理收藏」进入「一次规划，分批整理」。旧「整理」页面也有「全范围分批整理」入口，原手动单批交接保留。
3. 选择全部或未分类范围，决定是否包含备注、主动摘录和参考字典，点击「生成完整分片计划」。先在本机冻结整个范围，显示总条数、分片数和预算；不会发出请求。最多 10000 条、原始材料合计 30 MB；超限明确拒绝，不静默只取前面一部分。
4. 每片最多 20 条，同时按实际发送字符串长度和输出预算切分。输出预算按每片固定余量及每条保守估值计算，不是假装精确的 token / 费用计量。单条连同字典放不进预算时明确报错，不能丢掉这条继续。
5. 检查分片材料后确认发送。请求串行执行，失败即暂停后续片；完成回复逐片保存到本机。可只重试失败/中断片、继续全部未完成片，或发送当前片。已保存回复的片不再发送。
6. 刷新后从最近计划点「继续此计划」，重新配置并测试 AI 后再主动发送。没有后台自动发送、自动重试或跨刷新自动计费。
7. 校验所有已完成回复后，按页预览并跨页勾选应用；可以先处理完成片。一次没勾选的建议仍可稍后应用。应用和撤销复用既有本地版本、隐私、锁定和日志保护；请求完成不会自动写收藏。

## 状态与并发

- 计划及全部子交接批次同事务创建；任意一步失败整体回滚。
- 父计划存在 meta `ai-organize-plan:<id>`，保存范围计数、预算、分片状态与执行租约，不包含 Key 或服务认证。每片拥有独立 batchId，回复只允许属于本片且完整覆盖的编号，拒绝跨片、重复、缺项和额外字段。
- 大回复单独保存在子批次的 `directReply`，不在每次更新计划时重写所有回复。累计回复容量 30 MB，任务/材料/回复不进入普通 JSON 备份、手机 HTML 或 Cloudflare 投影。
- 一个计划只允许一个页面执行。持久租约为 120 秒，每次认领片时续期；开始请求前保存 attemptId。页面意外关闭后，租约到期才允许重试；中断片标为结果未知，不当作安全失败。旧 owner / attemptId 的迟到结果不能覆盖新尝试。
- 超时、取消或丢响应可能已经计费，重试失败或未知片必须主动确认。配置变化及页面离开停止后续片，并取消当前前台请求。
- 每片发送前重新核对资料、主库、策略、隐私和字典。参考字典为空时不扫描无关全库；有字典时按其隐私规则复核。策略或主库改变要求重新规划。
- 每条应用的编号状态与收藏变更、应用日志在同一事务里保存，避免页面中断后不知道哪些已写入。再次校验不会把已应用映射覆盖成无效。撤销只处理有应用日志的片，不会作废未发送的片；策略变化本身也不会阻止受版本保护的撤销。
- 最近列表展示最多 20 份未结束计划，不代表自动删除旧记录。「结束此计划」只归档并使建议失效，不撤销既有修改，也不清理本地日志；如需撤销，应先使用撤销入口。整库替换恢复会清理旧计划和子批次，防止旧库材料续接到新库。

## 验证

- `npm run verify`：203 项正式测试、类型检查和生产构建全部通过；原 `verify:v02` 的 22 项及手动 AI `verify:p5` 的 37 项也全部通过。

- 正式测试新增 11 项：300 条完整覆盖、按字符/输出预算分片、超长单条拒绝、10001 条和空范围拒绝；计划创建原子性、并发执行和过期租约、迟到响应、刷新持久化、严格分片覆盖、隐私/策略、部分应用、恢复清理及应用中断。
- `verify:organize-plan` 专项浏览器 13 项通过：300 条／15 片，第二片一次合成 503 后暂停；刷新续接，单独重试失败片，再发送剩余 13 片；总请求为 16 次，其中只有失败的第二片重复。
- 300 条建议一次只渲染 50 条，跨两页取消两条后先应用 298 条，再应用余下 2 条，没有再次调用模型；应用后人工改过一条，整计划撤销 299 条并保留那一条。
- 专项记录所有目的 origin，全部为 `https://api.deepseek.com`（测试替身），无 Cloudflare 请求。私密、禁止 AI、删除项及默认备注/摘录均未进入发送内容，Key 未进入本地存储。
- 报告：`.verify/reports/organize-plan.json`；截图：`.verify/organize-plan/plan.png`。真实 DeepSeek / 兼容服务仍需要用户自配凭据验收；本轮没有调用真实付费服务。
