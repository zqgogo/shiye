# 收藏筛选与待看状态边界（2026-11-06）

## 产品规则（替代旧的本地未读收件箱规则）

普通收藏只负责保存、分类、标签和检索，不再提供已读/未读功能。阅读进度仅属于待看（待处理/完成及历史）。本地「收件箱」原本按 inboxUnread 过滤，且导入统一标未读，因此完整导入后仍会大量显示，容易被误认为未入库；现移除该导航入口，旧 #inbox 链接兼容进入全部收藏。

- 新增收藏、粘贴入库、HTML 导入、待看转收藏、云端提交接收不再默认写入未读队列。
- 删除收藏的已读/恢复未读按钮、首页未读统计、手机添加的未读选项、收件箱接收编辑的未读选项及同步界面的未读展示。
- 侧栏将「未分类」提升为常用入口，原收藏与分类完整保留。
- 保留「云端与收件箱」：其中云端收件箱专用于其他设备提交的待接收内容。接收后入本机库，再手动同步；与旧的本地未读视图无关。
- 不对既有数据批量改状态、不重写旧备份；底层 inboxUnread/unreadFlag、旧备份迁移及同步协议字段暂留兼容，不在普通收藏界面展示和操作。旧版本显式字段仍可兼容读取。

## 查找

顶部全库搜索继续保留。全部收藏、分类列表、未分类及回收站增加页内搜索与筛选；搜索结果复用同一套分类/标签/来源/置顶筛选。

分类选择默认折叠；打开只列当前层级，每页 20 项。点击名称应用范围，箭头逐级浏览，支持完整路径搜索、根目录/祖先导航、全部分类及未分类。选中分类后默认包含子分类，可切换仅本级。分类路径完整值保留在提示中，长路径不撑宽筛选条。

组合筛选保留既有分页：改变筛选回第一页、退出批量选择并清除旧批量预览；清除搜索结果筛选保留顶部搜索词。筛选来源按本机来源元数据区分 HTML、扩展、手动/手机、JSON。全库索引检索保持原召回和排序，在其结果上应用所选范围。

「彻底清空整库/此范围」仍作用于整个范围，确认区明确标示不受列表筛选影响；按条件清理和批量选择沿用各自明确的范围。
