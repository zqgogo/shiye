# v0.2 第一轮实施与验收

日期：2026-11-04。版本标识：0.2.0-preview.1。方案见 [开发计划](../v0.2-cloudflare-ai-plan.md)，部署见 [自有 Cloudflare](../deployment/cloudflare-s1.md)。

## 已实现的本地可试用内容

- 插件弹窗「收藏当前页／快速访问」切换、记住页签、切回保留未保存表单。快速访问支持本地搜索、层级分类（含子分类）、置顶、最近、待看、每页 20 条、点击直接打开网址。没有新标签页接管，没有远程图标请求；本机私密记录仍可在本机访问。
- 通用 AI 设置支持 DeepSeek 与文本 Chat Completions 预设、手填/发现模型、Key 遮罩、合成文本和 JSON 测试、预算及参数配置、主动启用。配置变化令测试失效；Key 与配置仅当前工作台内存，刷新清除。现有导入专用 AI 仍独立使用其页面配置，后续统一配置体验另做。
- 提问包现在支持默认排除备注/摘录、用户主动勾选加入；可确认发送后直接显示回答和本次来源编号。整理包可选择允许参考分类/标签，过滤隐私关联目录；内置整理回复复用既有严格校验、预览、版本保护、应用和撤销。发送瞬间重新读取本地材料与隐私，旧包拒绝发送。
- AI 网络采用前台非流式请求、固定可信请求头、HTTPS/重定向限制、最终 content、完整 finish_reason 检查；超时/取消不自动重试。最小任务状态落本机表，开始先记结果未知，页面中断不会假称安全失败或自动再次计费。任务及 Key 不进入普通备份。
- Cloudflare 只读镜像设置、无记录握手、投影预览、分片进度、CAS 发布、同编号幂等重试、清空云镜像、独立发布/只读凭据。Worker + D1 SQL 迁移、手机只读网页和本地凭据生成器已交付。

## 验证

- `npm run verify`：类型检查、192 项正式测试、扩展生产构建通过。包含实际 SQLite 的 6 项后端协议测试，AI 适配器 4 项测试，以及原一万条导入/撤回回归。
- `npm run build:worker`：官方 Wrangler 4.157.0 dry-run 通过，Worker 与三份静态资源完成打包，没有登录或部署。另以官方 Wrangler 在独立本地 D1 中成功执行 0001_mirror.sql 的全部 6 条语句，没有使用远端库。
- `npm run verify:v02`：本轮专项 22 项通过。报告为 `.verify/reports/v02.json`；截图为 `.verify/v02/quick-access.png`、`cloud.png`、`mobile.png`。
- 回归 P4 的 47 项、P5 的 37 项、a11y 的 16 项均通过，旧手动通道、资料选择和工作台焦点保持可用。
- 浏览器 AI 使用合成响应，镜像通过实际 SQLite + Worker HTTP handler 联调，手机页在 Chrome 375×812 尺寸下登录、搜索、分页与退出；这不等于真实模型、Cloudflare 网络或 Safari 真机验收。

> 本文保留预览 1 的验收边界。2026-11-04 预览 2 已补齐全范围分片及续接，最新实现见 [分片整理实施记录](ai-organize-plan-2026-11-04.md)。

## 预览 1 当时尚未完成

- 通用整理当前每次最多 20 条，页面会提示超出范围。全范围自动分片规划、批次恢复和失败片重试为下一工作包，不能把当前按钮描述为已完成全库自动整理。
- 问答当前按纯文本展示引用及本次编号来源；未知编号会明确提示无效，不自动创建来源链接。没有网页正文就只依据已保存材料，不主动抓取网页。
- 主机权限逐次请求验证，Chrome 撤销当前域名授权时即时关闭通道并作废测试；Safari 权限差异仍需收口。刷新会清除配置和 Key，不提供虚假的跨重启保险箱。
- S1 镜像只能由电脑手动发布、手机只读；没有 S2 双向同步、持久 outbox、跨设备冲突裁决或自动后台调度。上传计划在本页保留，关闭页面后重新连接核对，不承诺跨刷新续传。
- 用户自有 Cloudflare 尚未部署，真实 DeepSeek/其他服务未提供凭据验证。单设备凭据撤销 UI、macOS Safari 包装/签名与 iOS 真机测试尚未完成。Safari 目标保留，当前不能标“已支持 Safari”。

后续优先级：先完成 P7 全范围分片及真实服务验证，同时完成 S1 自有账号部署和手机真机走查，再推进 Safari 包与 S2 的同事务队列基础。进度统一记录在 ROADMAP。
