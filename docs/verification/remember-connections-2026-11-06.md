# 凭据记忆与手机登录（2026-11-06）

- 电脑云端配置新增主动勾选的「在此设备记住发布凭据」。地址和凭据绑定，存于扩展本机 localStorage；这不是系统钥匙串或加密保险箱，不进入 IndexedDB 收藏备份或同步。共享设备不要开启。更改后端、断开或撤销权限会清除保存记录；取消勾选只删除保存副本，当前页面可继续使用。
- 刷新后进入云端页，已授予域名权限时自动做身份/发布权限检查，不自动上传或同步。云端库身份与上次不同则停止自动恢复，要求手动核对。未授予权限不自动弹授权窗口。连接超时保留凭据，不循环重试。
- 手机默认保持原有 8 小时会话；主动勾选「在此设备保持登录 30 天」后使用 HttpOnly / Secure / SameSite=Strict Cookie。凭据不写进手机 localStorage。无痕模式、清除站点数据或换网址/浏览器不能共享会话。
- 手机加载失败分开处理：401 才要求重新登录；断网、超时或服务失败保留已有会话和重试入口，不再把网络失败当作退出。
- 验证：15 项 Worker 协议测试；Edge 配置回归验证记住/刷新恢复/自动只读验证/移除；Edge 手机视口回归验证 Cookie 时长、刷新、模拟网络失败后无需重填即可恢复，及原提交收件箱流程。真机保留行为仍需用户验证。
