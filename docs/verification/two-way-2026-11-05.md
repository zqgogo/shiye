# 双机收藏同步验证

2026-11-05，v0.2 预览 5。实现范围与使用步骤见 [双机同步说明](../two-computer-sync.md)。

- 新增两套独立 IndexedDB 主库 + 实际 SQLite Worker 的正式集成用例，覆盖轮流新增/修改/删除/恢复、首次合并、路径归并、同网址冲突、删除编辑冲突、隐私撤回/隔离、丢响应、迟到本机写入、增量游标、分页、手机白名单、分类移动/删除、空目录、备份重建、共享编号手机收件和并发操作编号保护。
- `verify:two-way` 使用两个完全独立 Chrome 扩展配置，真实界面检查预览、确认、合并、备注、删除、离线冲突选择、无变化同步、隐私撤回、持久基线与手机共享视图。全部使用隔离合成数据，不读取用户收藏。
- 官方 workerd + D1 增加双机协议初始化、分批 120 条、同编号重试、手机隐私、并发版本守卫和旧镜像清空隔离检查。
- 实际 Cloudflare 更新不自动同步用户收藏；首次数据共享须在新页面预览并确认。真实两台物理电脑、iOS/Safari 与大库 CPU 配额不以本机测试代替验收。

最终本机检查：类型检查通过，正式测试 241 项通过（新增双机集成 16 项，包含负数拖动排序），部署工具 8 项通过；扩展构建为 `0.2.0-preview.5`，后端生产 dry-run 通过。双独立浏览器与手机专项 13 项、官方 workerd + D1 22 项、原 v0.2 回归 22 项、云端收件箱专项 16 项均通过，报告无页面异常。

已在现有 Cloudflare 部署运行增量迁移并更新后端/手机页，线上身份握手、只读/提交/发布隔离和 v2 协议检查通过；既有应用凭据不变。没有替用户上传、合并或删除真实收藏，首次同步仍需新界面预览确认。
