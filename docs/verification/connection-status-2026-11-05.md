# Cloudflare / AI 配置状态与修改流程

日期：2026-11-05。版本：`0.2.0-preview.6`。本轮只更新扩展的配置管理和显示，不改后端、不轮换凭据，也不读取用户真实收藏或调用真实 AI。

## 显示与使用

- 「设置与管理」新增两张连接概览卡；侧栏常驻简短状态。AI 助手也显示当前模型、开启及测试状态，避免必须进配置表单才能判断。
- Cloudflare 分为未配置、地址已保存但缺凭据、地址未保存、配置修改待验证、验证失败、已连接。展示后端域名、验证时间，以及共享收藏/待看镜像两个独立版本。
- AI 分开显示普通设置是否保存、问答测试、整理输出测试和主动开启状态。只通过问答测试时明确标为“问答可用，整理待测”。
- 配置页优先显示摘要，已验证后收起长表单；使用“修改地址或凭据”“修改 AI 配置”展开。进行中的测试也允许修改，改动会取消旧请求。
- 状态表示本次工作台中最后验证的结果，不持续探测网络。保存地址或普通设置不等于已验证、已开启。

## 保存边界

| 内容 | 本机持久保存 | 同一工作台切页 | 刷新/重开 |
| --- | --- | --- | --- |
| Cloudflare 后端地址 | 是 | 保留 | 恢复地址，待填凭据 |
| Cloudflare 发布凭据 | 否 | 保留在内存 | 清空 |
| AI 供应商、地址、模型、模式和预算 | 点击“保存普通设置”后保存 | 保留 | 恢复已保存值 |
| AI Key | 否 | 保留在内存 | 清空 |
| 验证结果、时间和 AI 开启状态 | 否 | 保留 | 不恢复，重新测试 |

普通配置用严格白名单保存，不包括 Key、测试状态、收藏内容或请求日志，不参与收藏同步与普通备份。普通设置无法保存时显示错误，不能以成功状态掩盖。模型列表不代替连接测试。

## 核对及修复

1. Cloudflare 连接提升到工作台上下文：切页不再丢凭据/验证状态；刷新仍清空敏感信息。
2. 握手同时核对镜像身份和 v2 同步协议/发布权限，reader 或 submitter 不再被误判为可用于电脑同步的连接。
3. 地址变化清掉旧发布凭据；凭据、地址或域名权限变化立即撤销验证，旧请求结果不能恢复新配置。
4. 同步面板与收件箱面板原先使用相同 React key，连接失效时会留下孤立旧面板；现分别设置独立标识，失效后一起撤下。
5. AI 每次复测先撤销对应旧通过标记；文本失败关闭通道并撤销整理验证，整理失败不冒充可用，仍允许已经验证的问答。
6. AI 改模型、Key、预算等立即取消旧请求、关闭通道、撤销测试；更换供应商或 API 域名清旧 Key 和模型列表。迟到成功或错误不覆盖当前配置消息。
7. 域名权限撤销及时显示并要求重新授权；主动断开只清内存凭据，保留地址、本机收藏、发布快照和同步基线。
