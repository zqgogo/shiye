# 手机缓存与手动更新

默认 2 小时，在页面刷新时判断是否需要更新；没有后台轮询。更多筛选里的更新间隔可选 1、2、6 小时，或仅手动。同步最新按钮始终可主动刷新。

刷新仍会并行读取轻量身份和权限接口，确认登录有效及库身份一致；命中缓存时不读取镜像分片或共享记录分页。缓存显示上次更新时刻，不将缓存冒充最新数据。登录校验失败会清除缓存并要求重新登录。

记录缓存在当前网址的 IndexedDB，不含登录凭据。退出或重新登录清除镜像缓存；本机临时提交副本独立保留。缓存内可能保留上次同步的数据，云端删除或隐私撤回要在下一次更新后反映。浏览器清理/驱逐缓存后会重新下载；存储失败不会把读取报成失败，会提示本次未保存缓存。

Edge 隔离脚本验证：两小时内刷新不增加镜像下载请求；同步最新强制下载；将缓存时间调至三小时前会重新下载；退出清除镜像缓存但保留临时副本。原登录、分类、提交和收件箱流程一并回归通过。
