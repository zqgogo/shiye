# 手机目录与收藏浏览优化（2026-11-06）

## 行为

- 收藏页将搜索、范围、筛选和手动同步集中为紧凑工具区，收藏卡片显示两行标题及一行网址/分类。
- 当前层级的子分类最多显示 3 条；不随分类数量增加而扩展。点击目录行切换到对应分类的收藏页。
- 「查看全部 N 个」或搜索栏旁「目录」进入独立目录页，收藏页不在原地展开长目录。
- 独立目录每页 20 条，支持名称/完整路径搜索、逐级进入、返回祖先和根目录、查看当前分类收藏、进入未分类。
- 「返回收藏」恢复原列表及滚动位置；选择新的分类则回到列表顶部。目录页中的导航不会提前改变收藏筛选。
- 目录预览可收起，浏览器本机记住收起选择；不随收藏同步。搜索收藏时隐藏目录预览，优先展示结果。
- 收藏保留「包含子分类」开关，默认包含；网站筛选、排序、缓存间隔置于折叠工具区，原有语义保留。
- 深层路径在顶部只显示根入口及最后两级，完整路径保留在目录搜索和分类选项中，不用多行长路径挤占内容。
- 添加记录的分类选择在手机使用全屏对话框，避免四周留白挤占选择区。保存/发送逻辑不变。

## 验证

运行 `scripts/verify-cloud-inbox.mjs` 的隔离 Edge 验证：500 多个分类仍只有 3 行预览；搜索时隐藏预览；收起选择刷新后保留；26 个根分类分为 20+6 两页；完整路径搜索、进入子级、应用分类、包含子级开关、返回滚动位置、320px 窄屏无横向溢出；同时回归登录、两小时缓存、强制同步、手机添加、电脑接收、发布状态核对及退出清缓存。

构建：`npm run build:worker`。截图在 `.verify/cloud-inbox/mobile-explorer.png` 和 `category-picker.png`。

本次验证使用 Edge 手机视口，不等同于 iPhone Safari 真机验证。页面使用原生 DOM、标准 flex、details 和 dialog；本次不重建 macOS Safari 扩展，手机网页由 Worker 静态资源升级。
