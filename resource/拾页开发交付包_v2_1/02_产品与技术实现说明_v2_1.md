# 拾页 · 产品与技术实现说明 v2.1

2026-10-27。配套文件：01_UI设计稿_v2_0.html、03_AI开发任务书_v2_0.md。本文件为本交付包的统一实施依据，已整合此前讨论；不需要翻阅旧版本，不采用“新条款覆盖旧正文”的组织方式。产品暂名拾页。

## 01 交付边界与技术路线

目标是个人收藏与待看工作台：先快速收集，随后查找、分类和按需使用 AI。v1a 本地优先、唯一可编辑主库，Chrome / Edge 扩展工作台是默认形态；React + TypeScript、Vite 构建扩展页面，Dexie 管理 IndexedDB，本地搜索使用 MiniSearch 或经过中文召回验证的替代实现。具体依赖版本在建项时选稳定版并锁定，不从单文件原型直接发布。扩展弹窗、service worker、工作台在同一扩展 origin 下使用同一数据服务。纯网页与扩展不天然共用存储；网页退路必须先验证受控桥接，不能默默建第二个可编辑库。切换浏览器配置须完整备份迁移、确认后停止旧主库写入。

v1a 包含独立待看、收藏收件箱、未分类、分类与标签、收藏置顶、最近打开 15 条、搜索、多链接粘贴、浏览器书签 HTML 导入、完整 JSON 备份恢复、手机只读收藏快照、手动 AI 交接；内置 AI 是默认关闭的可选模块，真实配置、测试成功及用户启用后可直接提问和整理，不依赖云同步。v1b Worker+D1、账号认证和手机在线编辑另行实施；不把它们作为本地版前置。Safari 专项、PWA、分享菜单、自动正文提取、自动链接检查、Agent、系统提醒、多用户协作不属于当前范围。

原型是交互参考而非生产工程：它以内存数组演示、不持久化，AI 连接和答案都是模拟；文件解析示例不能替代正式导入器，手机导出与恢复也未完成全部需求。生产实现以本文的边界、模型和验收为准。不要复制原型中的遗留字段和校验当作正式协议。

## 02 信息架构与视觉

保留原型的暖白背景、浅色侧栏和森林绿主色。背景 #F7F7F2、表面 #FFFFFF、侧栏 #F0F1E9、主文 #202A25、主色 #385C48、边框 #E4E7DE；次级文字在实际背景上验证对比度。正文系统字体，标题可用系统衬线字体，不依赖在线字体、缩略图或 favicon。桌面侧栏约 218px、内容区边距 32–40px；小屏导航折叠，主要触控目标至少 44px。表格可横向滚动，长链接换行不撑破布局。

日常菜单：首页、待看、收件箱、未分类、全部收藏。我的分类：最多 8 个手动置顶分类、有序排列、全部分类入口。工具：AI 助手、设置与管理。最近打开从首页进入；设置集中备份导入、分类策略、回收站及 AI 通道设置。不要恢复低价值菜单或高低价值筛选。

首页直接提供多链接粘贴输入框、“预览链接”和“从浏览器书签导入”入口。粘贴和文件导入有清楚的页内切换，共享预览组件；不要把所有输入、映射与结果挤进一个小弹窗。资料选择使用宽弹窗，提问页面保留给问题与回答。

## 03 待看、收藏、收件箱的关系

待看是独立阅读队列，不是收藏字段、分类或标签。加入待看仅保存 URL、标题、可选备注和加入时间，不进入收藏收件箱，不要求分类。原网页被打开不自动完成。完成待看仅改变队列状态，不删除已存在的收藏；提供单次撤销，以及“已完成”历史入口供恢复，历史默认不出现在日常列表，需用户主动清理，不自动永久删除。

转入收藏：展示标题、可选分类和备注；确认后原子地新增收藏并完成对应待看。新收藏 inboxUnread=true；未选分类则 categoryId=null。取消、数据库失败时待看不改变。相同 URL 已收藏时禁止重复创建，展示现有收藏与“查看”“完成待看”动作，不自动覆盖分类或备注。收藏里的链接也可加入待看：保留原收藏，只新增/恢复队列记录；完成待看不影响原收藏。活动待看按 URL 归一化键去重；历史中有相同记录时可重新激活并更新加入时间，不无限复制。收藏与待看用不同 ID，不依赖脆弱的对象共用；可保存关联收藏 ID 但应能处理收藏删除/恢复。

收件箱只显示未读新收藏：inboxUnread=true 且未删除。未分类只显示 categoryId=null 且未删除。已分类的新收藏也出现在收件箱；标记已读只改变未读，不改变分类。打开详情、原网页、分类修改、AI 整理不自动已读；提供单条/全部已读和恢复未读。删除收藏时隐藏于日常列表，恢复保留原分类和未读状态。

取消所有高/普通/低价值、价值待判断等字段与规则；不要求 AI 评级，不依据很久未打开自动删除。不用数值评分的另一种名字重新引入。保留用户主动设置的收藏置顶、分类、标签和备注。旧 valueLevel/valueReason 可以在升级前备份后从活动模型移除，旧 JSON 导入忽略这些字段并提示，不映射为待看或置顶。

## 04 分类、标签、详情与搜索

分类为一级实体，一条收藏至多一个分类；null 表示未分类。标签多选，用于跨分类描述主题。分类 ID 稳定，改名不改 ID。左侧最多 8 个常用分类，超限明确提示，可取消与调整顺序；当前未置顶分类在内容标题体现即可。全部分类支持名称搜索、全部/置顶/非空筛选、按名称/条数排序，收藏数量排除回收站；同名排序以 ID 兜底。分类选择器支持输入搜索，默认“暂不分类”。删除分类须展示影响并确认迁移到其他分类或未分类，不能连带删除收藏或改变未读。

详情分开保存来源描述、AI 用途、人工备注、主动保存的选中文字。标题必填、URL 仅 http/https；选中文字上限 4,000 Unicode 码点，超出明确提示，不静默截断。人工备注不被 AI 覆盖；人工锁定可保护分类、标签等支持字段。编辑有保存/取消、未保存草稿离开提醒和版本冲突提示。

收藏搜索覆盖标题、URL、描述、AI 用途、备注、选中文字、分类与标签；支持全库/当前分类范围。待看有独立搜索，不混入收藏结果；需要跨域时明确结果分组。记录工作台打开过的最近 15 个不同收藏；外部直接访问无法可靠统计，不伪称完整浏览历史。索引可重建，不当作主数据；分类标签改名后更新相关索引。本地专用仍可在本机检索。空库、无匹配、索引重建和故障状态要区分。

## 05 扩展弹窗与快速收集

弹窗读当前 tab 的标题和 URL；用户主动使用时可通过 activeTab/scripting 获取所选文字，右键链接取 linkUrl，右键选中文字取 selectionText；不常驻扫描所有网页。浏览器内部页等权限受限时提示并允许手填合法网址。弹窗提供“仅加入待看”和“保存收藏”两个明确动作。前者忽略分类且不进入收藏库；后者提供可搜索分类选择，默认未分类，保存后进入收件箱。不要给待看套一层强制分类。

保存使用稳定 UUID 和事务，确认持久化后才显示成功。弹窗关闭前未确认的写入用原 UUID 查询核对，不新建 ID 盲重试。重复收藏展示已有内容，用户可查看或明确更新；不覆盖人工字段。分类已失效则要求重选或明确保持未分类，不悄悄转移。后台写入失败保留输入，支持重试；插件不能读取主库时不能显示假成功。

## 06 多链接粘贴与书签 HTML 导入

粘贴页支持每行或空白分隔多个 URL，先解析不联网抓标题；缺标题时使用域名/URL 并标注未提取。浏览器书签导入页有独立文件选择、文件名及说明，当前只支持常见 Netscape bookmark HTML。JSON 恢复在备份恢复入口，不能把普通链接导入和整库恢复混为一谈。

解析为 ImportRow：原行号、原始 URL、规范化 URL、标题、完整原目录路径、状态、原因、是否勾选、目标分类。HTML 用惰性文档或纯解析器读取链接及 DL/DT/H3 树，不挂载到活跃页面，不执行脚本、不加载图片/样式和其他资源；正式解析器应有字符/节点/深度限制，处理文件编码与 BOM、空文件、非书签文件和损坏结构。文件示例上限 3 MB、单批 1,000 条可在 P0 校准并统一配置，超限说明原因，不静默丢条。

预览保留所有行，包括重复和无效行。顶部显示总数、可新增、重复、无效，下面表格展示复选框、标题/完整链接、原目录、状态与具体原因。支持全部/可新增/重复/无效筛选、全选可新增、清空选择，显示总已选数。禁用无效和确定重复行，但不能让它们直接从预览消失。保存目标可选待看或收藏；待看按活动队列去重、收藏按收藏库去重，切换目标重新算状态并提示会重置选择，不能静默清空选择。

URL 规范化保守处理：解析 HTTP(S)、规范主机大小写和默认端口，保留会改变内容的 path/query/hash；不一概删 hash、合并 http/https、去 www 或尾斜线，不靠相似标题自动合并。可将疑似重复作为提示交用户看差异。已有收藏但不在待看，可加入待看；已有待看但未收藏，可新增收藏，是否完成原待看需要明确选择，普通批量导入不默认完成。

导入收藏时列出“原目录 → 目标分类”的映射表，每组显示条数，可搜索选择已有分类或保持未分类；不未经确认自动创建分类，不直接复制所有层级。保留 sourceFolder/importBatchId 作为来源信息，待看也保留导入来源。提交前显示选择总数、目标与目录映射；再次检查去重及分类引用。解析和预览不写数据库。首版按受限单批在一个数据库事务中新增记录与导入批次，失败整体回滚，避免半批写入却报全失败；取消在写入前生效。稳定批次 ID 与行 ID 支持结果未知后的核对，重复提交不重复新增；文件指纹帮助识别重复导入但不能代替行级去重。成功页面显示实际新增、跳过、拒绝数量和目标入口。

## 07 提问资料选择与回答空间

提问页只放问题框、已选条数和少量标题摘要、选择资料按钮、直接提问/手动提问包及回答区。选择资料打开宽弹窗，按分类与关键词组合筛选，可查看仅已选。资料列表展示全部匹配项，不能截断前 60 条或只提交当前可见项；很多条时可滚动或用虚拟列表，但数据与选择语义必须完整。显示匹配数及跨分类总已选数。

选择状态用 Set<bookmarkId> 存储，切分类/关键词不清空；“全选筛选结果”选取当前匹配的所有可发送条目，“取消筛选结果选择”仅取消当前匹配，“清空已选”清空全部。关闭弹窗后保留选择并更新摘要；完成按钮返回提问页面。后台收藏改变时按稳定 ID 清理已删除/隐私受限项，显示排除说明。按问题检索是本地召回，追加候选供核对，不宣称可靠语义理解或自动搜索互联网。

选全仅表示选资料，不等于授权发送。内置模型有上下文预算，发送前展示条数和输入估算；超限要求缩小选择或明确分批策略，不偷偷只发送部分、不直接对 1,000 条全量发请求。手动包也有明确字符上限。直接回答在页面内显示，引用回到当次快照中的收藏；未知引用标为无效，不生成不存在的来源。服务商失败后保留问题和选择，可手动生成材料包。

## 08 数据结构与本地事务

使用 bookmark、readingItem、category、tag、settings、aiTask/batch、appliedChange、importBatch、tombstone 等存储。定义在 reference/domain.ts；该文件是接口起点而非已完成业务模块。IndexedDB 主键使用稳定 UUID；书签与待看不共享同一个表行。URL 归一化键建立非唯一索引，业务服务处理重复和墓碑语义。IndexedDB 索引不能依赖 boolean/null 作为有效索引键：未读/删除/待看状态可用明确字符串或 0/1 派生字段查询，业务模型布尔值不直接当索引键。schemaVersion 单调升级、迁移在事务内，不删除库后重建来逃避迁移。

持久编辑 revision 与本地快照保护序号 localRevision 明确区分；v1a 可一起递增。转换待看、写入收藏、导入批次和应用 AI 时使用事务。任何网络、文件大解析、hash 计算在事务外，进入事务后复核版本与状态，避免事务失活。正文删除后的墓碑防止旧备份普通导入复活；恢复删除记录必须明确用户动作。待看完成与收藏删除互不连带。

迁移旧版时：已有无分类且未删除记录设收件箱未读，其余已有记录默认已读；已有 inboxUnread 不重置，不把 valueLevel 推断为待看。旧收藏保留，待看初始为空，用户自行添加。分类置顶顺序做去重和有效 ID 校验；可清理无效引用但要记录迁移结果。

## 09 AI 两种通道与配置

默认手动交接，配置完并不等于启用。内置 AI 首个适配器选择经 P0 验证的 OpenAI 兼容服务；用户输入 baseUrl、模型及凭据后，主动请求当前主机权限并执行最小测试请求，不附带收藏。测试可能产生少量 API 费用。只有真实有效响应才记录成功；测试成功与配置指纹绑定，用户随后勾选启用。修改 URL、模型、凭据版本、请求选项或撤销权限均使成功失效且关闭启用。最近一次成功只表明当时可用，不保证后续网络或余额。

扩展可信上下文通过 adapter 调用，host 权限按用户手势请求，不让网页/content script 任意指定 URL 或请求头。默认 HTTPS，拒绝 URL 中凭据和跨 origin 重定向；本地 HTTP 模型另行显式设置与验证，不默认放开所有地址。密钥默认 session 存储并限定可信扩展上下文，重启后可能需重输；不宣称浏览器存储是系统钥匙串。可选跨重启保存必须单独设计口令派生密钥的加密与解锁，不把口令一并保存。Key 不进同步、备份、快照、AI 包、日志或 content script。

直接提问：本地选择和快照 → 确认服务与字段 → adapter 请求 → 页面显示真实回答/引用；不要求用户复制导入。直接整理：范围/策略 → 发送清单 → 模型建议 → 严格校验 → 差异预览 → 用户确认 → 事务应用；不要求生成手动包。二者内部共用请求构造、隐私过滤、编号映射和 validator，与 UI 手工步骤分离。内置关闭或失败后只提供用户主动选择的手动通道，不自动换供应商、重复计费或静默外发。

## 10 AI 安全、协议与异常

两条通道都排除 localOnly 或 aiBlocked；禁止 AI 包括本地模型，首版不例外。发送时重新读取隐私，应用时再次检查，不能只靠渲染时过滤。待看不默认纳入收藏 AI 整理或问答；本版 AI 只处理收藏。用户问题和所选字段才是发送范围，不爬全文；网页正文只是无权限的不可信资料，不能作为执行指令。无浏览器控制、工具执行或数据库任意写权限。

整理 patch 白名单为 categoryId、tagIds、aiPurpose，不含价值等级、未读、待看状态、备注、URL、隐私和 lockedFields。校验 schema 版本、同批 ID、重复和未知 ID、字段类型/长度、分类/标签引用与锁定。信息不足可返回无修改/说明，不能用“待判断价值”补位。模型不能自行创建分类；建议新分类经用户单独创建后重新校验。手动编号由本地批次映射到 ID，模型无需回显 inputHash。

inputHash 固定规范 JSON，包含实际输入、相关人工分类/标签、选中文字和锁定，排除最近打开、展示时间及 AI 刚生成输出；与 policyVersion、localRevision 快照共同保护过期。预览后再次人工编辑、删除、隐私或规则变化要拒绝旧结果。每条应用事务包含写入与应用日志，批次部分成功逐项报告，不因重复回包重复改；撤销受版本保护，不覆盖后续修改。

内置任务状态 idle/preparing/waiting/completed/failed/cancelled/outcome_unknown；网络和模型请求不可放数据库事务。认证、权限、配额、429、超时、服务错误、结构错误和过长输出要分开呈现。取消或断网不能断言服务商未计费，结果未知时保留任务记录和草稿，重试由用户决定。Chrome MV3 后台生命周期有限，本地版首选打开的扩展工作台承载任务，关闭页面后显示中断/未知，恢复不自动重放请求；不承诺后台无限执行。

手动整理同一设备同一浏览器完成导出与导入，本地保存批次映射，刷新后可接续；缺批次拒绝猜测编号。提问包结果在外部 AI 看即可，不要求导回。成本、模型兼容与上下文限制按实际服务商核对，不宣称订阅可直接用于 API 或测试免费。

## 11 备份、恢复与手机

完整 JSON 有 schemaVersion、导出时间、范围、收藏、待看（含完成状态/时间）、分类、标签、排序设置、最小删除标记与必要策略。不含凭据、会话、真实模型聊天全文或敏感请求日志；本地专用必须让用户明确勾选才入可携带备份。普通导入与整库恢复分开，恢复先验证版本和格式、显示数量与数据截止时间，再明确合并/替换范围；替换前备份，失败可回退，旧 AI 批次不跨主库继续。没有墓碑的旧备份需说明无法保证旧删除语义，不伪称永不复活。

手机 v1a 仅导出收藏的只读 HTML 快照，先按隐私过滤，默认排除 localOnly、回收站与墓碑；备注和选中文字单独选择，aiBlocked 不等于禁止用户普通导出。待看不纳入手机快照，本地主队列先做好；手机端待看同步/收集属于后续明确扩展。快照标明导出时间、不自动更新，支持分类筛选与关键词组合；无脚本也展示静态列表。文本转义、JSON 防闭合脚本、URL 只允许 http/https，禁止执行笔记/标题中的 HTML。文件持有者可读全部字段，不公开托管私人快照；本地文件使用不佳时只能用有访问保护的退路。

## 12 可选 v1b 同步（独立阶段）

Worker+D1 为唯一可选同步后台，OneDrive 仅备份。服务端 revision、每记录最新 changeVersion、按版本增量游标和最小墓碑；拉取按版本升序，游标只推进到实际收到并落本地的最大版本。dbEpoch 在 pull 返回、push 携带并在事务校验；恢复旧备份、重建或清理破坏同步历史时主动换 epoch。纪元不匹配暂停所有未确认写入，包括扩展收集队列，保留本地专用与草稿，重新同步后人工核对，不自动换纪元重放。普通部署无损迁移不随意换 epoch。

创建稳定 ID，相同 ID 及相同业务内容可返回 unchanged，不同内容冲突，后来编辑/删除记录不能被重复创建覆盖或复活。普通更新采用 baseRevision/baseValues 字段检查，字段冲突整条拒绝；删除恢复需预期版本。写入响应丢失先拉取核对，不确定就提示冲突，不声称天然安全重试。无需独立长期幂等表，但允许误报冲突换取简化。

待看若在该阶段选择同步，独立实体与收藏同样有版本和删除语义，不能借完成队列删除收藏；隐私不允许上传时继续本地。具体认证、Access 与收集 token 的只新增权限须先验证，收集 token 不能查询或修改全库，避免公开代理。手机在线编辑保存以服务端确认为准，离线不承诺待上传队列。

## 13 工程模块与实施顺序

建议 src/core 放纯模型、规范化、导入计划、隐私、AI 校验与变更计划；storage 放 Dexie schema/迁移、事务仓库和导入批次；extension 放消息校验、权限与凭据服务；adapters/ai 放供应商请求协议；ui 放路由、待看、收藏、收集预览、分类、资料选择、AI 和备份组件。content script 仅获取用户授权页面数据，不能访问任意密钥与模型接口。剪贴板权限失败提供可复制文本。扩展 CSP 采用独立脚本，不 eval 模型文本或原型 HTML。

实施顺序：P0 验证公司电脑安装限制、主库持久化、文件导入器、手机快照与实际 AI 往返；再做模型/迁移及仓库、待看收藏状态、收集与导入预览、分类搜索和资料选择、手动 AI、备份快照，最后接默认关闭的内置 AI。v1b 不得自动混进来。不在 P0 前承诺固定工期。

## 14 验收与交付要求

数据：新增、编辑、关闭重开、迁移、导入去重、删除恢复与备份恢复保持一致；不能只测内存。待看转收藏必须原子，重复转换不重复新增，完成后原收藏不受影响。所有价值等级在正式模型、UI、搜索、导出与 AI schema 中彻底去除。

资料选择：用超过 60 条和至少 500 条资料验证全部展示、全选匹配集、取消匹配集、跨分类保留、仅已选和隐私即时排除；模型超限不能静默截断。导入：有效/重复/非法 URL 所有行可见、按目标重算去重、目录映射、状态统计、未勾选不写、重复确认、损坏文件和事务失败均正确。

AI：无测试或未启用不能发；测试不带收藏；修改配置立即失效；真实目标模型直接问答/整理不经过手工包；失败、过期、锁定、非法字段、无效引用、取消与重试受控；Key 不泄漏。手动和内置共用校验不共用强制手工步骤。页面：键盘、焦点、Escape、超长标题、空状态、窗口缩放、触控和对比度有实际检查结果。

交付正式源代码、锁文件、构建命令、扩展安装说明、数据格式与迁移说明、测试输出和已知限制；不能把原型的示例结果或语法检查标成真实浏览器/服务商/D1验证。测试使用脱敏样本，不读取用户真实收藏或使用真实凭据，除非用户明确提供并授权。

## 15 页面状态与交互验收矩阵

| 页面 | 入口与正常路径 | 必须处理的异常/空状态 | 保存与退出规则 |
|---|---|---|---|
| 首页 | 直接粘贴多链接→预览；选择书签文件→导入 | 无输入、全为无效、超限 | 输入不因解析错误丢失；预览不写库 |
| 待看 | 添加、打开、完成、转入收藏 | 空队列、已收藏、已在队列、标题为空 | 打开不自动完成，转换失败仍待看 |
| 收藏详情 | 编辑分类/标签/描述/备注、锁定、置顶 | 版本冲突、分类已删除、长度超限 | 保存/取消分开；离开未保存草稿提醒 |
| 收件箱 | 未读收藏；单条/批量已读 | 当前筛选为空、收藏被删除 | 已读不删除收藏、不改变分类 |
| 全部分类 | 搜索、置顶/取消、排序 | 无匹配、置顶满 8 项、分类被引用 | 删除需迁移关联；不是连带删除收藏 |
| 收集预览 | 状态表、选择目标、目录映射、勾选提交 | 重复/非法/损坏、目标切换重算 | 切目标先说明选择将重置；返回保留输入 |
| 提问资料 | 全选匹配集、取消匹配集、跨分类补选 | 大量结果、已删除/隐私变化、超预算 | Set<ID> 为真实选择；关闭保留选择 |
| AI 设置 | 编辑配置→测试→主动启用 | 拒权限、认证、余额、超时 | 配置变更立即失效；Key 不显示到日志 |
| AI 整理 | 范围→直接或手动→校验→预览→应用 | 未返回项、非法/重复项、过期、锁定 | 用户确认后逐条事务；撤销受版本保护 |
| 导出恢复 | 选择范围→预览→确认→结果 | 格式/版本不支持、墓碑缺失、空间不足 | 替换前备份；失败不破坏原库 |

所有按钮在运行中有清楚状态，禁用重复提交；长任务可取消，结果未知与失败不能混淆。页面仅用文本、颜色和图标共同表达状态，键盘能进入选择、关闭和确认控件。

## 16 模型与运行时字段约束

| 字段/对象 | 建议初始约束 | 授权边界 |
|---|---|---|
| id | 稳定 UUID，首次创建生成 | 重试不得换 ID |
| title | trim 后 1～300 Unicode 码点 | 人工/捕获可写，AI 不直接改 |
| originalUrl | 仅 HTTP(S)，上限 8,192 字符 | URL 内含账号密码拒绝，模型不能改 |
| sourceDescription / aiPurpose | 各最多 4,000 码点 | 来源描述与模型用途分开 |
| note | 最多 20,000 码点 | 人工字段，AI 不覆盖 |
| selectedText | 最多 4,000 Unicode 码点 | 必须用户主动保存，不静默截断 |
| categoryId / tagIds | 分类存在或 null；标签最多 30 个去重 | 分类整体字段；标签整体数组，非集合猜合并 |
| inboxUnread / pinned | 独立布尔业务字段 | 不因分类或 AI 自动变化 |
| reading.status | pending / completed | 完成队列不改变收藏实体 |
| privacy / lockedFields | 两独立标记、受支持字段枚举 | 不允许模型构造任意字段路径 |
| revision / localRevision | 单调正整数 | 事务比较；时间戳不是冲突依据 |
| importBatch | 稳定 ID、原文件哈希、计划摘要、状态 | 不能靠文件名判定重复 |
| aiTask | 当次配置指纹、快照 ID 与状态 | 不包含 Key；输入快照不默认进入云端 |

字段限制集中在 core/constants，不散落到表单。TypeScript 类型不提供运行时安全：所有文件、扩展消息、AI 回复及 HTTP 输入都必须经过运行时 schema。移除所有价值等级，不用 unknown/high 等旧枚举占位。

## 17 IndexedDB schema 与迁移建议

```ts
// Dexie 建模样例；具体表名与索引需随业务查询验证。
// indexes 使用 string/number 派生键，不直接索引 boolean 或 null。
db.version(1).stores({
  bookmarks: '&id, canonicalUrl, categoryId, [lifeState+unreadFlag], createdAt, lastOpenedAt, localRevision, *tagIds',
  readingItems: '&id, canonicalUrl, [status+addedAt], relatedBookmarkId, localRevision',
  categories: '&id, name', tags: '&id, name', settings: '&key',
  policies: '&id', tombstones: '&[entityType+id], deletedAt',
  aiTasks: '&id, kind, state, createdAt',
  handoffBatches: '&id, createdAt, status',
  handoffItems: '&[batchId+n], [batchId+bookmarkId], status',
  appliedChanges: '&id, taskId, bookmarkId, appliedAt',
  importBatches: '&id, fileHash, status, createdAt',
  importItems: '&[batchId+sourceKey], entityId'
});
// lifeState: 'active' | 'deleted'; unreadFlag: 0 | 1，写库时从业务字段派生。
// 若已有生产库，新增 version(n+1).upgrade；不能重用 version(1) 或删除重建。
```

迁移前导出可恢复备份，迁移只处理缺失字段，不重置已有用户状态；历史 valueLevel/valueReason 只在备份里保留历史痕迹，活动 schema 迁移后删除。文件中的旧字段可以忽略并在恢复预览说明。迁移失败中止启动编辑，提供备份/重试，不创建空库掩盖错误。索引的有效 key 与业务字段 null 的缺失要区分；未分类可通过全量候选过滤或专用 categoryKey='uncategorized' 派生键查询。

## 18 关键写入事务与并发保护

```ts
// 待看转收藏：在事务外计算规范 URL、长度校验与输入快照。
await db.transaction('rw', db.readingItems, db.bookmarks, db.tombstones, async () => {
  const queued = await db.readingItems.get(queueId);
  assertPendingAndRevision(queued, expectedQueueRevision);
  const existing = await findActiveBookmarkByCanonicalUrl(canonicalUrl);
  if (existing) throw new ExistingBookmark(existing.id); // UI 展示，不静默改写
  assertNoDeletedRecordResurrection(canonicalUrl, await relevantTombstones());
  await db.bookmarks.add(newBookmark); // inboxUnread=true；分类可为 null
  await db.readingItems.update(queueId, {
    status: 'completed', completedAt: now,
    localRevision: queued.localRevision + 1,
    relatedBookmarkId: newBookmark.id
  });
});
// 任何一步失败整体回滚；不得“新增失败仍完成队列”。
```

```ts
// AI 应用：hash/结构检查在事务外；版本、权限、字段锁与引用在事务内复核。
const checked = await validateSuggestionOutsideTransaction(taskId, itemId);
await db.transaction('rw', db.bookmarks, db.handoffItems, db.appliedChanges, async () => {
  const item = await getTaskItem(taskId, itemId);
  if (item.status === 'applied') return { status: 'unchanged' };
  const current = await db.bookmarks.get(itemId);
  assertActiveAndRevision(current, checked.expectedLocalRevision);
  assertPrivacyLocksAndReferences(current, checked.patch);
  const next = applyWhitelistedFields(current, checked.patch); // 分类、标签、AI用途
  await db.bookmarks.put(next);
  await db.appliedChanges.add(makeConditionalUndoLog(current, next, taskId));
  await markTaskItemApplied(taskId, itemId);
});
```

应用结果与已接受分析基线的更新必须带版本保护；未成功应用不能标为分析完成。撤销读取 appliedLocalRevision，只在条目仍是该版本时恢复本次变化的字段，再递增版本，形成新修改。用户已改过任何相关字段时拒绝覆盖并给差异。

导入采用同批事务写入记录、importItems、importBatch=applied。网络不进入事务；hash 与解析先完成。首次提交前持久化计划 ID 或不可变计划摘要，恢复时先查是否 applied，不能因为 UI 等待超时而重复创建全批。跨页面并发写入时，事务内再次检查 canonicalUrl、分类引用和墓碑；确定重复跳过并计数，非重复校验失败应返回拒绝理由而不是默默丢弃。

## 21 错误码、恢复动作与可选同步 HTTP

| 本地/AI错误码 | 界面说明 | 允许下一步 |

| GET /api/sync/pull | 管理员；epoch/cursor/limit（建议≤200） | dbEpoch/items/nextCursor/hasMore；含分类、标签、策略和墓碑 |
| POST /api/sync/push | 管理员；epoch/schemaVersion/changes（建议≤50） | 逐项 applied/unchanged/conflict/deleted/notFound/rejected |
| POST /api/capture | 设备只新增 token、epoch、稳定ID、白名单字段 | 可指定分类的新收藏，默认未读；最小回执，不读改全库 |

400 结构错误不写，401 需认证，403 不自动重试，409 EPOCH_MISMATCH 暂停，429 在业务写入前拒绝；超时/5xx 不推断“没写”。200 不代表批次全成功。push 内每条原子，分项结果持久后才能移出 outbox。服务端按 revision/baseValues 比较字段，任何字段冲突整条拒绝；删除/恢复保守要求匹配版本。create 重复与后来编辑/删除状态不能混淆。队列送出期间冻结内容，新编辑进入后续操作，不悄悄替换原请求。

最小墓碑与最新变更序号可省完整历史日志，但并不提供事件审计或 ABA 识别；别额外承诺“精确识别一切旧请求”。D1 样例只供 P0，含真实鉴权、字段授权与 epoch-CAS 的完整服务要另外实现。

## 23 持久化、删除、历史与恢复细节

收藏删除先软删除，默认 30 天后正文可在用户确认维护时清理，最小墓碑保留；自动清理任务不属于首版。待看完成是完成状态，不是删除，完成历史可恢复；用户主动清理历史才移除相应记录，不能连带清理收藏。空库恢复、合并备份和替换主库的删除语义不同，恢复页面必须明确模式及影响。

引用收藏的待看记录遇到收藏删除时保留原 URL/标题与队列，关联标为失效，不能通过查看关联使收藏复活。待看转收藏遇到相同 URL 的删除记录时，提示恢复原收藏还是创建新收藏，两者都是显式人工动作；普通导入不得未经确认突破墓碑。已完成的队列再次加入待看可恢复 pending，记录新的加入时间；完成历史不是永久审计日志，不强制保存每一次循环。

多窗口同时操作使用仓库事务与 localRevision，不能靠 UI 内的一个布尔锁。文件备份导出读取一致的逻辑快照，不把期间不同时间读取的分类、书签和墓碑拼成所谓完整备份；大库时以短读事务/明确快照阶段处理，计算和写文件在事务外。下载生成仅表示发起下载，不能宣称文件一定存入了硬盘。
