# 拾页 · AI 开发任务书 v2.1

请实现本包的收藏工作台。先读 02_产品与技术实现说明_v2_0.md，再打开 01_UI设计稿_v2_0.html 理解视觉和流程。技术说明是统一需求依据；UI 是内存演示，不是生产源代码。不要依赖旧版文档补范围。遇到矛盾按技术说明并记录实现决定。

## 执行规则

默认 Chrome / Edge MV3 扩展工作台，React + TypeScript + Dexie；锁定依赖。主库唯一，存储持久化。保持暖白、绿色、分组导航、独立待看、页内粘贴/导入预览及宽资料选择窗。先 P0 后实现，不部署云资源，不自行接入真实密钥，不混入 v1b。纯网页与扩展不能假设共享存储。

## A：P0 验证

在用户实际环境确认扩展安装、同 origin 主库写入和关闭重开；解析真实脱敏浏览器书签 HTML（含多层目录与损坏输入）；验证手机只读 HTML；对用户选定的模型供应商验证真实测试请求、权限和直接问答/整理。没有凭据可先实现 mock adapter 并明确待用户验证，不假装测试通过。记录限制并调整，不用无限后台运行方案绕开 MV3 生命周期。

## B：核心数据与状态

建立收藏、独立待看、分类、标签、设置、导入批次、AI 批次与应用日志、墓碑；实现迁移和版本事务。不要保留 valueLevel、价值理由或 AI 评级，包括导出 schema。待看不要求分类；完成不影响已有收藏；转收藏原子新增+完成，重复时显示已有收藏。收件箱未读与未分类正交；查看/改分类/AI 处理不自动已读。完成待看可撤销并可查历史。

## C：收集与分类

弹窗提供仅待看/保存收藏；收藏可搜索分类。首页多链接直接粘贴；文件导入单独输入、共用预览。所有新增/重复/无效行展示原因；目标切换说明选择重置，重新去重；收藏按目录映射到现有分类或未分类，不擅自建目录。完整保留来源。仅确认勾选的可新增条目写入，事务失败整体回滚，重复提交不重复新增。JSON 恢复单独入口。

分类一级、标签多选；最多 8 个置顶分类并可排序，搜索筛选不丢状态。详情编辑有取消、锁定、隐私与版本保护。最近打开 15 条只记录工作台行为。支持本地搜索及索引重建。

## D：提问与两条 AI 通道

提问资料弹窗显示全部匹配，可用虚拟列表但不得只取 60 条。Set<ID> 保留跨分类选择，支持全选匹配集/取消匹配集/清空全部，隐私受限与删除项即时剔除。回答页面不被长候选列表挤占。选择资料不是发送授权，模型容量不足不得静默截断。

默认手动交接，保存同设备批次映射/hash，校验预览后应用。内置 AI：用户配置+真实测试通过+主动启用后，直接问答、直接整理；不强迫用户生成或导入材料包。隐私过滤、字段白名单、锁定、过期校验及预览事务与手动通道共用。Key 只在可信上下文，不进备份、日志、同步或材料包。失败保留问题、选择与草稿，用户可选择手动交接，不能自动换模型或重试计费。现有原型中的固定回答/分类只是 mock，正式实现不能保留伪结果。

## E：备份、手机与验收

完整 JSON 包含待看与完成状态、收藏、分类、标签、设置、策略及墓碑，排除凭据；恢复先预览/备份并支持回退。手机快照仅正式收藏，独立筛选分类与关键词，安全文本渲染，不含私密或删除内容，不自动同步。待看手机同步后置。

按 reference/验收清单.md 逐项执行。每完成一个模块汇报具体行为、测试和限制；只运行过的项目才写通过。最后交源代码、构建产物、锁文件、安装与迁移/备份说明。不要把语法检查、静态样例或本地 SQLite 检查冒充浏览器/服务商/D1 实测。


## 逐阶段可交付任务

### P0：验证，而非直接写完整工程

先检查当前仓库结构和 AGENTS.md 等约束；记录目标浏览器版本、扩展安装策略与主库位置。用最小扩展验证 popup→同 origin 仓库→工作台→关闭重开；用脱敏 HTML 验证文件读取和层级目录。真实模型验证只有在用户提供并授权凭据后执行，未获得时标为待验证，不为了过关模拟网络成功。

输出 P0 记录，明确通过、失败、未测及调整。不要创建云资源，不把依赖未来服务的流程伪装成已联通。

### P1：纯核心、迁移与仓库

先实现 reference/domain.ts 对应正式类型、运行时 schema、保守 URL 规范化、字段授权与隐私过滤，再实现 Dexie 仓库和迁移。UI 不直接改数组或数据库，跨模块调用用 application use case。命名统一 originalUrl/canonicalUrl，清理全部 valueLevel/valueReason；原型的命名可作为输入适配，不作为正式持久协议。

检验旧数据迁移、重复创建、预期版本不符、事务故障回滚、未分类索引、关闭重开。不要用 TypeScript Partial 代表字段授权，不把 boolean/null 直接当成有效索引键。

### P2：工作台与独立待看

保留 UI 样式和菜单分组，实现首页、待看、收件箱、未分类、全部收藏、最近打开、详情、回收站。待看转收藏新增+完成同一事务；已收藏时查看现有记录，不自动新建。完成历史和撤销可恢复 pending，不连带删除收藏。

检验：打开不自动已读/完成；已分类新收藏仍在收件箱；已读未分类仍在未分类；已有收藏加入待看、完成后收藏字段不变；空状态和长标题可操作。

### P3：捕获、粘贴、真实 HTML 导入

实现扩展两条保存动作、右键所选链接/文字、首页直接多链接输入和独立文件页。预览必须逐行保留新/重复/无效状态，统计与表格一致。按目的地重算去重并解释重置选择；收藏目录映射支持搜索选择，保留 sourceFolder。

至少用 Chrome/Edge/Firefox 脱敏导出格式验证 DL/DT/H3；不能复制原型简化 DOM 结构假设。解析不得执行脚本或加载第三方资源。事务提交记录批次、行 ID 和结果，重复确认/失败重试无重复或半批假成功。

### P4：分类、搜索与提问资料

完成分类改名、引用迁移、最多8个置顶及排序、多标签、本地索引重建；不能用分类删除顺带删除所有收藏。资料选择宽窗、全部结果完整、Set<ID>跨分类保留；全选是全部匹配集，虚拟列表仅改善渲染，不裁剪真实选择。

使用500条数据检查搜索、仅已选、分类过滤、取消筛选结果和隐私变更。提问页面空间用于回答和引用，资料列表不能再次平铺挤占；超过模型预算有明确处理。

### P5：手动 AI、校验与可撤销应用

先完成固定输入结构、指纹、策略版本、批次和编号映射持久化。导出前可预览实际字段，导入严格 JSON 校验；预览和应用分开，事务内再次核对版本/隐私/锁定/引用。AI 只改分类、标签、AI用途，不评级、不改未读或待看，不覆盖人工备注。

正常/重复/过期/未知编号、非法字段和脚本字符串都要有测试；部分成功逐项报告；撤销不覆盖后续修改。刷新能续接本地批次，换主库/缺映射明确拒绝。

### P6：备份、恢复与手机快照

完整 JSON包括独立待看与完成状态、收藏和墓碑；凭据等不导出。恢复页面区分合并与替换，替换前先备份、显示截止时间和数量。以恢复后深度数据核对证明，不只比较数量。

手机只读快照首版仅收藏，私密字段过滤、文本安全渲染、分类+关键词组合、无脚本基础列表；在实际手机浏览器验证，不能用桌面缩窗代替全部测试。

### P7：内置 AI 可选模块

在手动通道验证稳定后接可选 adapter，测试指纹与启用门槛严格绑定；密钥隔离与主机权限有真实验证。直接问答在页内回答，直接整理进入校验和预览，无复制/导入操作。

模型调用异步状态、取消、限流、鉴权失败、页面关闭和结果未知均保留可恢复草稿。没有承诺精确费用、无限后台运行或所有供应商兼容；真实服务商测完才标可用。可独立关闭模块，不影响收藏与手动通道。

## 每阶段汇报模板

交付行为：具体页面、数据或协议发生什么变化。
验证证据：执行的命令、测试结果和实际环境；未执行的写未执行。
数据风险：迁移、事务或凭据边界，如无新增则简要说明。
剩余问题：未实现、仅示例、依赖用户凭据/设备的项。
下一步：只进入已授权范围内的下一阶段，不自动部署 v1b。
