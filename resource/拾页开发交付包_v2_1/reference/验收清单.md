# 开发验收清单

以下为正式开发的待执行项目，本包未声称这些均已通过。

- [ ] 扩展工作台和弹窗共享持久主库，重启不丢，纯网页不会偷偷写第二份。
- [ ] 待看独立，不要求分类；可完成、撤销、恢复历史；已有收藏不被完成动作删除。
- [ ] 转入收藏原子成功后才完成待看；取消、失败和重复提交不丢内容/重复创建。
- [ ] 新收藏默认未读；标已读不改分类；无分类已读仍在未分类中。
- [ ] 正式 schema/UI/AI/备份均没有价值等级及遗留强制校验。
- [ ] 分类搜索、8 项上限、排序、改名/迁移和关联索引更新正确。
- [ ] 多链接和真实书签 HTML 逐行显示新增、重复和无效原因，保留标题及原路径。
- [ ] 目标切换明确提醒、去重重新计算；逐目录映射正确；未勾选不入库。
- [ ] 超限/损坏文件、XSS、非法链接、节点深度和网络资源不触发执行或加载。
- [ ] 同文件再导、同批重复确认、事务中途失败或响应不确定时可核对，无半批假成功。
- [ ] 资料选择超过 60 条及 500 条，全部可查看，全选所有匹配而不是可见项。
- [ ] 搜索/切分类保持已选；仅已选、取消筛选结果选择、清空全部语义准确。
- [ ] 模型超限显式处理，不静默截断，不因选全就自动发送。
- [ ] 内置配置变更使测试失效；真实测试不带收藏；启用后能直接问答与整理。
- [ ] 两条 AI 通道均排除隐私内容，白名单严格，锁定/过期/重复/恶意回复不能越权。
- [ ] Key 不进日志、备份、导出、同步、URL 和 content script。
- [ ] 完整 JSON 可恢复待看/收藏/分类/墓碑，版本错误或失败不损坏主库。
- [ ] 手机收藏快照可打开、分类筛选搜索，脚本注入无效且不公开私人文件。
- [ ] 键盘焦点、Tab、Escape、长链接、小屏与错误提示已实际检查。
- [ ] 未运行项目标待验证，提供真实测试记录和局限。
